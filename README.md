## The joke

> At 3 a.m. my cat dropped a dead mouse on my chest like a waiter presenting the chef's special, then sat back waiting for a tip.

## What it does

`main.py` writes a single one-line joke about cats to `/output/entry.txt` — 127 characters, one line, UTF-8, no padding and no explanation after the punchline. It uses only the Python 3.13 standard library.

## How to run it

```bash
python3 main.py
cat /output/entry.txt
```

Set `MAKEFUN_OUTPUT_DIR` to write the entry somewhere else instead of `/output`.
